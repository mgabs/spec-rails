# Excluded workflows

Workflows generated by the pinned OpenSpec (`openspec-version`) that have no CLI-free port in `skills/ports/`. The overlay leaves their generated files untouched and logs them as still requiring the `openspec` CLI. The drift test requires every upstream workflow to be ported or listed here.

| Upstream skill | Reason |
| :--- | :--- |
| `openspec-new-change` | Redundant: `propose` scaffolds `openspec/changes/<name>/` and its `.openspec.yaml` without the CLI. |
| `openspec-verify-change` | Not part of the six ported workflows; relies on CLI status output. Port when needed. |
| `openspec-onboard` | Interactive CLI tour; teaches the `openspec` CLI, which target repos do not need after bootstrap. |
